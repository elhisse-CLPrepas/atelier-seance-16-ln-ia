# Exemple pédagogique Situation-Actuelle-IA

Le dossier 08-accompagnement-S15-S16 est une copie des traces produites en S15. Pour le groupe, il sert de cas de démonstration, distinct du projet de chaque candidat.

Téléchargez rejouer-exemple-s16.ipynb et exécutez ses six cellules dans l’ordre avec Python 3. Le répertoire demo-situation-actuelle-ia est réservé aux exports fictifs. Le notebook original conserve les sorties historiques ; les anciens scripts restent des traces de travail et peuvent dépendre du dossier S15.

Le message de référence est une proposition IA acceptée, pas une rédaction humaine S14 antérieure. La prédiction historique vient de l’assistant. Recueillez votre propre prédiction avant de lancer la comparaison. Le message final compte 284 points de code ; une longueur acceptable ne vérifie pas les faits. Réouverture personnelle et décision du pilote restent à documenter. Aucun message LinkedIn n’est envoyé par cet atelier.
