# Missions et prompts pour la séance 15

Vendredi 13 novembre 2026 · Module 04

## Agent lecteur

01 · Relire deux versions

Lis seulement la trace fictive de S14 et le journal source fournis. Compare A et C corrigée. Rends un tableau avec les colonnes affirmation, passage d’appui, invariant, formulation qui change. Si un fait manque, inscris « à confirmer ». Arrête-toi après le relevé, sans modifier de fichier.

## Agent chargé du plan de tests

02 · Concevoir des tests

La règle d’exercice est : pour un message renseigné, si la longueur dépasse 400 caractères, afficher « À raccourcir », sinon « Longueur acceptable ». Propose un essai exactement à 400, un autre à 401 et un texte bref dont le sens doit être confronté à la source. Donne les entrées et les prédictions. Distingue explicitement les prédictions des exécutions observées. Rends le plan et arrête-toi.

## Agent contradicteur

03 · Chercher un contre-exemple

Lis la fiche fictive de Samira et le message « Ce guide doublera vos notes. ». Relève l’affirmation principale. Indique ce que le test de longueur peut montrer, puis cherche le passage qui justifierait le gain annoncé. Si ce passage manque, signale-le. Propose une reformulation fidèle et la référence à vérifier. Je prendrai la décision.

## Assistant de préparation

04 · Préparer le notebook S16

À partir de ma trace de S15, organise les données dans un tableau « champ, valeur, source ou justification ». Utilise projet, public, besoin, proposition, action et format. Laisse les absences visibles. Recopie la condition et les deux sorties observées sans les inventer. Signale les éléments qui nécessitent encore l’examen du formateur. Rends le tableau ; aucune diffusion.

Les données utilisées avec un assistant connecté sont fictives. Le pilote conserve la décision.
