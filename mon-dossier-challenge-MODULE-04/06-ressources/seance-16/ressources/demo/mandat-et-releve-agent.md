# Agent relecteur du Module 04

## Mandat à donner
Confiez une mission de lecture sur les seuls fichiers fictifs guide-pratique-v2-a-relire.md, journal-corrections-v1-v2.md et variantes-exemple-rouvert.md. Le résultat attendu est un tableau. Le droit d’exécuter un fichier, de le modifier ou de diffuser une communication n’est pas requis par ce mandat.

> Repère le projet, le fait et l’action dans le Markdown. Cite le passage avant et le passage réellement présent sous « Message corrigé ». Compare le sens à une ligne nommée du journal. Rends quatre colonnes : critère, observation vérifiable, écart, reprise proposée. Indique « non observable dans les pièces » pour toute action que tu ne peux pas attester. Arrête-toi après le tableau.

## Exemple de réponse préparé pour la classe

| Critère | Observation vérifiable | Écart | Reprise proposée |

| Fidélité | Le Markdown dit « Le journal explique ce qui a changé et pourquoi. » Le journal S12 comporte une colonne « Raison et contrôle à réaliser ». | Aucun écart repéré sur ce fait précis. | Le candidat retrouve la ligne « Forme — accessibilité ». |

| Action | La section finale demande un extrait du journal. | Le comptage ne suffit pas pour écarter une seconde demande reformulée. | Lire le texte complet. |
| Geste candidat | Fichier de démonstration disponible. | Réouverture individuelle non observable dans les pièces. | Le candidat ouvre le vrai fichier sur son poste devant le pilote. |

Ce tableau est une sortie pédagogique préparée. Une nouvelle réponse d’agent sera confrontée à la même source. L’autorité de validation reste au pilote.
