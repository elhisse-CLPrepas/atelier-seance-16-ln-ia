# Poursuivre le Module 04 en S16

Le dossier commun est `atelier-seance-15-ln-ia/mon-dossier-challenge-module04`.
Il contient déjà la progression S13 à S15. Conservez ce dossier unique.

1. Ouvrir `OUVRIR-SEANCE-16.html` dans le dossier commun.
2. Reprendre les vrais fichiers `04-communication/donnees-pour-s16.json` et `04-communication/message-court-projet.md`. S'ils manquent, terminer les exports S14/S15 avant de poursuivre avec le projet personnel.
3. Ouvrir `05-automatisation/communication-assistee.ipynb`, choisir le mode fichier et contrôler la racine affichée. Prédire, exécuter, corriger puis rouvrir le Markdown sur disque.
4. Ajouter le contenu renseigné de `07-portfolio/entree-preuve-16.md` au portfolio existant `07-portfolio/preuves-module-04.md`. Conserver les entrées antérieures et les décisions du pilote.
5. Préparer `07-portfolio/relais-module-05.md` avec les éléments réellement relus.

Les affiches et supports S16 se trouvent dans `06-ressources/seance-16/ressources`. Les cas fictifs sont séparés des productions personnelles. Aucune validation pédagogique n'est attribuée automatiquement.
