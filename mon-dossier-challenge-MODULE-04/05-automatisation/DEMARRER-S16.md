# Préparer et ouvrir S16

Le notebook `communication-assistee.ipynb` est le carnet candidat copié du pack local S16. Ses zones de prédiction et de correction restent à renseigner. Il n'a pas été exécuté dans Jupyter pendant la préparation de ce dossier.

1. Dans l'atelier S15, compléter les six champs avec leurs appuis puis exporter les données S16. Enregistrer le vrai export sous `04-communication/donnees-pour-s16.json`. Aucun faux export rempli n'est fourni.
2. Vérifier aussi `04-communication/message-court-projet.md` : le notebook recherche la rubrique « Version humaine S14 ». Si nécessaire, renseigner `TEXTE_HUMAIN_S14` dans la cellule 1.
3. Ouvrir le notebook dans Jupyter ou VS Code avec un noyau Python 3.
4. En cellule 1, choisir `MODE_SOURCE = "fichier"` et contrôler la racine affichée. Le mode `exemple`, proposé par défaut, utilise un cas fictif et ne représente pas votre projet.
5. Exécuter les cellules dans l'ordre. Prédire avant de modifier ; renseigner les appuis, la correction et son motif. Le notebook signale les données et étapes manquantes.
6. Après export, rouvrir `04-communication/variantes-communication-projet.md`, retrouver la correction et enregistrer le notebook avec ses sorties.
7. Compléter l'entrée S16 du portfolio après observation réelle.

Le mode d'emploi original est conservé dans `06-ressources/seance-16/`. Il décrit aussi un kit avec des sources fictives supplémentaires qui ne sont pas toutes recopiées ici. Pour ce dossier, utiliser le cas intégré au notebook ou les véritables exports S14/S15.
