# Automatisation · exécuter puis rouvrir

## Préparer

Installer ou utiliser Python 3 et un environnement Jupyter ou VS Code avec prise en charge des notebooks. Le double-clic sur l'atelier HTML ne lance pas Python.

Ouvrir `communication-assistee.ipynb` depuis ce dossier. Conserver une copie du carnet avant de reprendre un travail déjà renseigné.

## Exécuter les six cellules

1. Choisir `MODE_SOURCE = "fichier"` pour son projet. Vérifier la racine affichée : elle doit désigner ce dossier Module 04. Au besoin, renseigner `RACINE_CANDIDAT` avec son chemin absolu Windows sous forme de chaîne brute Python.
2. Vérifier les six champs et les appuis importés de S15, puis retrouver la version humaine S14.
3. Lire les trois brouillons complets avant changement.
4. Prédire, changer une seule valeur, exécuter et comparer.
5. Renseigner le passage brut exact, sa correction, le motif, l'appui et le canal.
6. Exporter puis ouvrir le fichier `04-communication/variantes-communication-projet.md` dans un éditeur. Retrouver le texte corrigé et enregistrer le notebook avec ses sorties.

## Si l'export reste en attente

Relire le message de la cellule : compléter le champ demandé ou corriger l'appui. Ne pas supprimer les contrôles pour produire un fichier. Le mode `exemple` et la répétition Web sont des exercices ; les identifier comme tels dans le bilan.
