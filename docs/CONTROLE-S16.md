# Contrôle du pack S16

Édition 1.0 · du notebook au message corrigé · lundi 16 novembre 2026. Public du Challenge 100 Jours. Pilotage et décision pédagogique du Prof. Abderrahman El Hisse. Parcours de 90 minutes, avec 30 minutes facultatives.

| Objet | Vérification |
|---|---|
| Sources | Les cinq archives, le prompt maître et les exemples d’automne ont été confrontés. Le dossier SOURCES-ET-ADAPTATIONS détaille les versions d’été et les choix pour S16. |
| Présentation | 18 diapositives et leurs notes dans le PowerPoint, 18 pages au PDF. Les pages ont été rendues et relues. La projection Web reprend leurs titres et leurs situations de travail. |
| Fiches | Conducteur de 4 pages. Fiche candidat de 3 pages avec 22 champs remplissables. Corrigé de 2 pages. Bilan de 2 pages avec 12 champs. Les Word ont été rendus, les PDF ont été inspectés et les formulaires remplis puis rouverts sur une copie de test. |
| Données de S15 | Le cas du guide a été produit par la fonction d’export du pack S15 d’automne. Le schéma, les six valeurs et leurs six appuis sont contrôlés. Un JSON incomplet ou un champ dupliqué donne un message de reprise. Le second cas Samira a également été exécuté. |
| Six cellules Python | Le carnet candidat vierge et la démonstration ont été exécutés de haut en bas dans des processus Python 3 initialisés à neuf. Dans la démonstration, les sorties concordent avec le relevé et le script autonome produit le même Markdown, octet pour octet. |
| Environnement Jupyter | L’environnement de préparation fournit Python, sans noyau IPython/Jupyter installé. Le test dans l’interface Jupyter reste à effectuer sur le poste de projection. Le script verifier-noyau-s16.py réinitialise les sorties et lance un nouveau noyau Python 3 sur un poste équipé de nbformat et nbclient. |
| Variation et correction | Pour le cas du guide, les longueurs court et accessible restent 114 et 166. Le professionnel passe de 174 à 184 après la précision du public. Le texte corrigé et rouvert compte 177 caractères. |
| Garde de l’export | Une action vide avec le véritable schéma S15, un appui manquant, un changement identique, un passage brut introuvable ou une correction factice empêchent un nouvel export. La réouverture vérifie la section finale. Le second passage identique conserve l’existant. Un changement garde la version précédente dans historique/. |
| Atelier Web | En navigateur, projection, notes, modification du public, correction à 177 caractères, carte retournée, quiz à six réponses, aperçu de la trace et contenu des liens d’export du bilan et de M05 ont été examinés. Le carnet distingue la répétition JavaScript de l’exécution Python. |
| Sortie distribuée | Après extraction du ZIP, le projet a été recompilé et contrôlé. Les 32 ressources téléchargeables sont présentes dans la version statique et embarquées dans le HTML autonome. Les empreintes des fichiers livrés sont consignées dans EMPREINTES-SHA256.txt. |
